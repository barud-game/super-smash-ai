# Super Smash AI

Een 2D platform fighter in Godot 4.6 die zo veel mogelijk als Melee moet voelen.
De twist: er is geen vaste roster. Je verzint je eigen character in een gesprek met Claude,
en Claude balanceert en bouwt het.

Fan-project. Niet verbonden aan Nintendo. Alle characters zijn origineel.
